# ref: auraplan

**Tags:** `dark-elegance`, `night-scene`
**Source:** supplied 2026-08-25. Not stored on disk.

**The closest reference in the set to where Pixel Blade already is.** Workspace
brand. Warm-lit dark interior photograph fills the right; type occupies the
unlit left. Small tracked eyebrow, then a large light-weight caps headline whose
final word — `INTENTION` — is gold. Small dim body copy. A solid gold button
with dark text beside a ghost outlined button. A three-item icon-and-label strip
across the bottom, split by thin vertical rules. Top-left, a thin geometric line
mark beside a widely tracked wordmark.

**Teaches:** `accent-word`, `gold-ghost-pair`, `feature-strip`,
`dark-half-type`, and a logo lockup construction almost identical to the one
proposed for Pixel Blade.

**Caution:** almost none. This is the reference to measure our hero against.
Its palette is warm brown where ours is green-black, which is the only real
divergence.
